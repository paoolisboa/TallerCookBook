### Aplicación: **CookBook**

Aplicación móvil con React Native CLI, que consiste en un recetario de cocina Tradicional Colombiana que permite ver una lista de receta, navegar a los detalles de cada receta seleccionada. Además permite navegar a un formulario de adición de receta y un área de Tips culinarios dinámicos.

## Instrucciones de instalación y ejecución:
npm install
npx react-native run-android

## Lista de Tecnologías utilizadas:
